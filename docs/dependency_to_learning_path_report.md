## PowerShell编码兼容性修复（第四次优化）

### 问题识别
在跨章节修正完成后，发现脚本在Windows默认PowerShell环境下运行时会触发Unicode编码错误：

```
UnicodeEncodeError: 'gbk' codec can't encode character
```

主要原因是脚本中使用了 ✅、❌、⚠️ 等Unicode符号，在GBK编码环境下无法正确显示。

### 修复方案
1. **移除所有Unicode符号**: 将控制台输出中的所有Unicode符号替换为ASCII兼容标记
2. **统一标记标准**: 
   - [PASS] 替代 ✅
   - [FAIL] 替代 ❌  
   - [WARN] 替代 ⚠️
   - [INFO] 替代 🟢（绿色状态）
   - [WARN] 替代 🟡（黄色警告）
   - [FAIL] 替代 🔴（红色失败）
3. **保持路径逻辑不变**: 只修改输出格式，不改变任何业务逻辑
4. **测试验证**: 在Windows默认PowerShell下直接运行测试

**生成逻辑**:
- 从resolved_pre中筛选核心依赖
- 优先选择不同章节的核心前置
- 同章节内只选择高级别前置（L2、L3）
- 限制数量为前5个最重要的依赖

**用途**: 
- 用于前端展示硬前置要求
- 帮助学生理解学习路径的必要条件
- **不直接展示全部resolved_pre**，避免信息过载

#### 2. recommended_pre（推荐前置）
**定义**: 建议了解的相关知识点，有助于更好理解

**生成逻辑**:
- 主要从rel字段选择
- 补充部分resolved_pre中的次要依赖
- 限制数量为3个

**用途**:
- 提供扩展学习建议
- 帮助学生构建更完整的知识体系
- 作为可选的学习路径

#### 3. related_after（学完继续）
**定义**: 学习完当前知识点后建议继续学习的相关内容

**生成逻辑**:
- 查找依赖当前知识点的其他知识点
- 优先选择同章节的直接后续
- 限制数量为5个

**用途**:
- 提供学习路径的延续性
- 帮助学生规划后续学习
- 增强学习体验的连贯性

#### 4. unlock_reason（解锁原因）
**定义**: 解释为什么需要特定前置才能学习当前知识点

**生成逻辑**:
- 基于required_pre数量生成描述
- 结合知识点级别（L0-L3）提供难度说明
- 为学生提供清晰的学习路径解释

**用途**:
- 帮助学生理解学习路径的逻辑
- 提供个性化的学习建议
- 增强学习动机

#### 5. path_rank（路径排序）
**定义**: 知识点在学习路径中的推荐顺序位置

**生成逻辑**:
- 基于依赖数量计算基础分
- 结合知识点级别调整权重
- 数值越小越优先学习

**用途**:
- 为前端提供排序依据
- 支持个性化学习路径推荐
- 优化学习顺序

#### 6. path_role（路径角色）
**定义**: 知识点在学习路径中的角色定位

**角色类型**:
- **entry**: 入门点 - 无前置依赖的知识点
- **intermediate**: 中间知识点 - 有适量前置的知识点
- **advanced**: 高级知识点 - 前置依赖较多的知识点
- **hub**: 核心枢纽 - 被多个知识点依赖的重要节点

**用途**:
- 帮助学生理解知识点的重要性
- 支持学习路径的可视化展示
- 提供学习重点指导

### 重要说明

**resolved_pre vs required_pre**:
- **resolved_pre**: 用于机器判断的完整依赖集合，包含所有技术上的前置关系
- **required_pre**: 用于展示给学生看的精简依赖集合，只包含最核心的前置要求
- **设计理念**: resolved_pre保证算法正确性，required_pre保证用户体验

### 2. 路径生成算法优化

#### 多维度评估体系
**评估维度**:
1. **知识点级别** (level): L0-L3，越低越基础
2. **直接前置数量** (direct_pre_count): 直接依赖的复杂度
3. **解析前置数量** (resolved_pre_count): 总体依赖的复杂度
4. **关键词匹配** (keyword matching): 语义相似性
5. **章节特征** (section characteristics): 章节特定的学习路径

#### 智能筛选策略
**入门路径筛选**:
- 级别要求：L0-L2（相对宽松）
- 直接前置：≤5个
- 解析前置：≤20个
- 关键词匹配：基础概念类
- 章节适配：针对不同章节调整策略

**提高路径筛选**:
- 级别要求：L1-L3
- 直接前置：3-8个（适中）
- 解析前置：10-30个（适中）
- 关键词匹配：常用模型类
- 解锁关系：被入门路径解锁

**冲刺路径筛选**:
- 级别优先：L2、L3
- 关键词匹配：高级技巧类
- 复杂度识别：综合应用类
- 补充机制：确保路径完整性
