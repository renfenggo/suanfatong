# 前端结构 MVP 人工测试手册

测试对象：`build/app/outputs/flutter-apk/app-release.apk`

## 1. 安装与启动

1. 将 APK 安装到 Android 手机或模拟器。
2. 首次启动 App，确认没有闪退、白屏或长时间卡在加载页。
3. 进入首页后，检查底部导航、主要入口、返回键是否正常。

通过标准：
- App 可正常启动。
- 首页可见。
- 返回键不会导致异常退出或卡死。

## 2. 知识点详情页

重点测试以下 itemId：

| itemId | 重点检查 |
|---|---|
| `2.8.208` | 学习卡片 |
| `2.4.1` | 练习入口 |
| `2.7.16` | C++14 模板入口、动画入口 |

检查项：

1. 打开知识点详情页，页面不崩溃。
2. 有学习卡片的知识点应显示：
   - 一句话解释
   - 核心直觉
   - 什么时候用
   - 最小例子
   - 常见坑
   - 学完继续
3. 有练习入口的知识点应显示题目列表。
4. 点击练习题，应能打开外部网页；打不开时应有轻提示，不应崩溃。
5. 有 C++14 模板入口的知识点应显示模板入口，不应直接塞大段代码。
6. 有动画入口的知识点应显示动画卡片，点击后进入动画页面。
7. 没有某类数据时，不应出现空白大卡片、`null` 或未解析字段。

通过标准：
- 四类入口按数据存在与否显示。
- 点击行为正常。
- 页面没有明显乱码、溢出、遮挡或空壳区域。

## 3. 章节页

重点测试以下 sectionId：

| sectionId | 重点检查 |
|---|---|
| `2.8` | 动态规划学习路径、分层折叠 |
| `3.13` | 高级数据结构学习路径、跨章节前置、分层折叠 |
| `4.1` | 数论基础学习路径，不显示空前置区 |
| 普通章节 | 无学习路径时优雅降级 |

检查项：

1. 进入章节页，页面不崩溃。
2. `2.8`、`3.13`、`4.1` 应显示学习路径区域。
3. 学习路径应包含：
   - 入门路径
   - 提高路径
   - 冲刺路径
4. `2.8`、`3.13` 应显示“建议先补的基础”。
5. `4.1` 不应显示空的跨章节前置区域。
6. 知识点列表应按层级展示：
   - 核心主线
   - 常用进阶
   - 专题扩展
   - 冷门 / 可选
7. `advanced` / `optional` 默认折叠。
8. 点击章节页中的知识点，应进入对应知识点详情页。

通过标准：
- 学习路径、跨章节前置、分层列表都能看到。
- 折叠/展开交互正常。
- 普通章节没有空路径区域。

## 4. 动画页面

重点从知识点 `2.7.16` 或其他有动画入口的知识点进入。

检查项：

1. 点击动画入口后能进入动画页。
2. 动画标题、步骤、变量/容器信息能显示。
3. 点击下一步/上一步时状态变化正常。
4. 页面返回后仍能回到原知识点详情页。

通过标准：
- 动画页可打开。
- 操作不卡死、不崩溃。

## 5. 外链与网络

重点测试 `2.4.1` 的练习入口。

检查项：

1. 点击题目外链。
2. 手机应打开浏览器或平台 App。
3. 无网络时 App 不应崩溃。

通过标准：
- 有网络时能打开网页。
- 无网络或链接异常时有提示或安全失败。

## 6. 回归检查

快速扫一遍：

1. 首页能进入知识图谱。
2. 章节页能进入知识点。
3. 知识点页能返回章节页。
4. C++ 学习入口仍可用。
5. 旧 BFS 学习工具入口仍可用。
6. 页面中不出现明显 `null`、`[]`、`Instance of`。
7. 长标题不严重溢出。

## 8. 通过条件

可以进入下一阶段的最低标准：

- App 可安装并启动。
- `2.8.208`、`2.4.1`、`2.7.16` 三个知识点详情页可正常查看。
- `2.8`、`3.13`、`4.1` 三个章节页可正常查看。
- 学习卡片、练习入口、C++14 模板入口、动画入口至少各有一个样例可见。
- 学习路径和分层折叠可见。
- 没有阻塞性崩溃。
