## 3. 学习卡片 Schema 设计

### 3.1 字段列表（11个字段）

| 字段名 | 类型 | 必填 | 描述 | 自动化程度 |
|--------|------|------|------|-----------|
| one_sentence_explanation | string | 是 | 一句话通俗解释 | 低（需人工填写） |
| when_to_use | string | 是 | 什么时候用 | 低（需人工填写） |
| must_know_before | array | 是 | 必须前置知识 | 高（可从 direct_pre 提取） |
| nice_to_know | array | 否 | 推荐前置知识 | 中（可从 rel 提取） |
| core_intuition | string | 是 | 核心直觉/核心思想 | 低（需人工填写） |
| minimal_example | string | 是 | 最小例子 | 低（需人工填写） |
| common_traps | array | 是 | 常见坑/易错点 | 低（需人工填写） |
| compare_with | array | 否 | 易混淆对比 | 低（需人工填写） |
| practice_entry | string | 是 | 练习入口 | 低（需人工填写） |
| learn_next | array | 是 | 学完继续 | 低（需反向依赖查找） |
| learning_action | enum | 是 | 学习动作 | 中（可自动推断） |

### 3.2 学习动作枚举（6种）

| 动作 | 描述 | 适用场景 | 推断规则 |
|------|------|----------|----------|
| read | 阅读理解 | 概念性知识点 | 默认动作 |
| trace | 手动推导 | 状态转移、递推过程 | 名称包含"推导"、"过程" |
| code | 编写代码 | 实现类知识点 | 名称包含"实现"、"代码"、"模板" |
| prove | 数学证明 | 定理、公式类 | 名称包含"证明"、"定理" |
| solve | 解决问题 | 应用类知识点 | 名称包含"例题"、"应用" |
| compare | 对比理解 | 易混淆知识点 | 名称包含"对比"、"区别" |

### 3.3 字段设计理念

**核心目标**：让知识点更易学

**设计原则**：
1. **通俗化**：用大白话解释复杂概念
2. **结构化**：统一字段，便于前端展示
3. **可操作**：提供具体学习动作和练习建议
4. **关联化**：明确前置、后续、对比关系
5. **实用性**：聚焦实际应用和常见问题
